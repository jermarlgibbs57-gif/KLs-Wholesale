K L'S WHOLESALE ENTERPRISE WEBSITE
=================================

FILES
-----
index.html  = Main website
style.css   = Design and responsive styling
script.js   = Products, cart, animations and WhatsApp ordering

HOW TO USE IN VISUAL STUDIO CODE
---------------------------------
1. Open the "KLs_Wholesale_Website" folder in Visual Studio Code.
2. Open script.js.
3. Find:
   const WHATSAPP_NUMBER = "1473XXXXXXXX";
4. Replace it with the business WhatsApp number, including country code and digits only.
   Example:
   const WHATSAPP_NUMBER = "14735551234";
5. Save all files.
6. Open index.html in a browser, or use the Live Server extension in VS Code.

IMPORTANT
---------
The product prices in the website are PLACEHOLDER estimates for the website layout.
Confirm and replace them with K L's actual prices before publishing.

The business plan confirms the initial product range includes bottled water,
juices, Busta, Guinness, Malt, Mackeson, Carib, Stag, Heineken, Rude Boy,
Caribe, Orchid, Kool Kids and Caprison. This demo includes the main products
as cards; add the remaining products in script.js if desired.

The website does not process card payments. Orders are sent to WhatsApp for
confirmation, which fits the business plan's low-cost ordering approach.
